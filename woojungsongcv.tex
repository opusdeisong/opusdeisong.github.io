\section*{RESEARCH INTERESTS}
I study how to measure and guide the behavior of language models and agents in context.
\begin{itemize}
    \raggedright
    \item \textbf{Measuring model behavior:} Evaluating values in realistic responses \mbox{\href{https://aclanthology.org/2025.acl-long.838/}{[ACL~'25]}} and behavioral tendencies across tasks \mbox{\href{https://arxiv.org/abs/2609.32795}{[arXiv~'26]}}; examining the behavioral validity \mbox{\href{https://arxiv.org/abs/2509.10078}{[EMNLP~'26]}} and contamination \mbox{\href{https://arxiv.org/abs/2510.07175}{[EACL~Findings~'26]}} of questionnaire-based profiles.
    \item \textbf{Understanding agent decisions:} Studying how tool interfaces \mbox{\href{https://arxiv.org/abs/2510.07248}{[ACL~'26]}}, unreliable outputs \mbox{\href{https://arxiv.org/abs/2609.05587}{[arXiv~'26]}}, and information sources \mbox{\href{https://arxiv.org/abs/2610.03195}{[arXiv~'26]}} influence agents, and developing interventions to improve tool use.
    \item \textbf{Simulating human behavior:} Modeling how traits interact with situations \mbox{\href{https://arxiv.org/abs/2507.05890}{[TACL~'26]}} and characters change over time \mbox{\href{https://arxiv.org/abs/2606.05553}{[EMNLP~'26]}}; using diverse user simulations to evaluate and train tool agents \mbox{\href{https://arxiv.org/abs/2509.23124}{[ICLR~'26]}}.
\end{itemize}
